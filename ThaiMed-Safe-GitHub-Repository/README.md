## 📌 เกี่ยวกับโครงการ (About Project)
**ThaiMed-Safe** คือระบบเว็บแอปพลิเคชันที่ใช้ปัญญาประดิษฐ์ (AI) ในการประเมินและแจ้งเตือนความเสี่ยงการเกิดปฏิกิริยารีดักชันระหว่าง **ยาสมุนไพร/ยาแผนไทย** กับ **ยาแผนปัจจุบัน** เพื่อป้องกันอันตรายจากการใช้ยาร่วมกันของผู้ป่วย

## ✨ จุดเด่นของผลงาน (Key Features)
1. **Interactive Drug Checker:** ระบบเลือกรายการยาสมุนไพรและยาแผนปัจจุบันที่ใช้งานง่าย รองรับทั้งคอมพิวเตอร์และมือถือ (Responsive Web)
2. **Dual View Mode:**
   - **Mode ประชาชน:** แสดงผลด้วยภาษาที่เข้าใจง่าย เน้นการเตือนภัยและวิธีปฏิบัติตัว
   - **Mode แพทย์/เภสัชกร:** แสดงกลไกทางเภสัชวิทยา (Pharmacokinetics/CYP450 Enzyme) และอ้างอิงทางวิชาการ
3. **Clinical Safety Focus:** แก้ปัญหา National Pain Point ช่วยให้แพทย์กล้าจ่ายยาสมุนไพรคู่กับยาแผนปัจจุบันได้อย่างมั่นใจ

## 🚀 วิธีการติดตั้งและทดสอบ (Getting Started)
1. Clone หรือ Download Repository นี้ไปไว้ที่เครื่อง
2. เปิดไฟล์ `index.html` บนเว็บเบราว์เซอร์ใดก็ได้ (เช่น Chrome, Edge, Safari)
3. ทดลองกดเลือก **"ฟ้าทะลายโจร"** คู่กับ **"Warfarin"** แล้วกดประมวลผลเพื่อดูการแจ้งเตือนความเสี่ยงระดับสูง
